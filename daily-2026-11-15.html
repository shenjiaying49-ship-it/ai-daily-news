Section 01 — 通识精读（今日主线）
FOUNDATIONSChain-of-Thought Prompting Elicits Reasoning in Large Language Models
Jason Wei, Xuezhi Wang, Dale Schuurmans 等 9 人 · Google · 2022-01-28 提交 · 后发表于 NeurIPS 2022 · arXiv:2201.11903 · 通识计划第 9/20 篇
为什么是分水岭：在 R1 之前三年、在「用 RL 学出推理」之前，这篇论文发现了一个几乎零成本的方法：在提示里放 8 个带中间推理步骤的示例，大模型就能自己「想出」推理链。PaLM 540B 在 GSM8K 上从标准提示的 17.9% 跳到 CoT 的 56.9%（+39.0），仅 8 个示例就达到当时 SOTA，超过带 verifier 的微调版 GPT-3。它证明了三件事：推理可以是「写出来的 token 序列」；这个能力随规模涌现（10B 以下反而常为负收益，约 100B 才出现增益）；以及此后一切的伏笔——把思维显式化，它才能被检查、被监督、被强化。今天 ChatGPT 里每一段「让我想一想」的输出，源头都是这 8 个示例。

核心思想（讲给 12 岁）：问一个孩子数学题，他报出答案 42，你不知道他是算出来的还是蒙的。CoT 的做法是：给他看几道「写满步骤」的例题，他自然就会把步骤写出来。神奇的是，把步骤写出来本身就能提高正确率——就像你心算 17×23 容易错，但列个竖式就对了：不是你会了新知识，是纸和笔替你保住了中间结果，不让它们在脑子里蒸发。CoT 就是语言的草稿纸：模型把中间步骤写在上下文里，每一步的输出成为下一步的输入，多步计算不再挤在一次前向传播里。

原理机制（A→B→C）：A · 提示即程序——标准提示是「Q → A」，CoT 提示是「Q → 推理步 → A」，8 个示例把「先分解、再逐条推、最后才给答案」这个输出格式教给模型；没有参数更新、没有训练循环，全部发生在推理时；B · 上下文当工作内存——自回归模型每生成一个 token 都要重新读一遍上下文，中间步骤一旦写进上下文，后续每一步都能「看着它」继续算，多步算术的准确率瓶颈被外存绕开；C · 规模门槛与涌现——CoT 不是教新知识，而是把模型已有但隐式的多步计算显式化：模型内部得先有那几步计算，写出来才有增益；10B 以下内部计算不足，写出中间步反而暴露并放大错误；约 100B 起，显式化的收益才盖过噪声。论文原话：「chain-of-thought reasoning is an emergent ability of increasing model scale.」

与近期进展的联系：本周速递就是 CoT 的三条延长线——过程监督线：TOME-Math（2610.40394）从 2,118 本大学教材抽出 38 万条结构化推理步记录（命题-证明依赖链原样保留），全量微调较基座 +16.7 个百分点；Actor, Judge, or Teacher（2611.17167）发现推理步的正确监督位是「事后裁判」而非「事前演员」，把 GRPO 训练的 1.5B 模型在 ALFWorld 提到 82.9%；调度线：Value of Thinking（2611.16961）把「想多少」简化为「想不想」——推理按期望效用定价，延迟降 72.5% 分数不降；反面镜子：SO-Arena（2611.15777，HF 版面榜首 135 赞）发现能力第一的 System One 模型可靠性仅排第 7。产业侧的 Mirendil（见 05 深潜）把这一切推到终点形态：推理显式化 → 步骤可审计 → agent 接管整个预训练。

今日怎么读（15 分钟路线）：全文仅 4 页，是通识计划目前最短的一篇——先读 Figure 1（三种提示方式的对比，一图看懂）→ §3.2 结果（GSM8K 上 17.9→56.9 与「约 100B 才涌现」的曲线）→ §4 消融（为何解法对、方程错——数学题也该写步骤）→ §6 讨论收尾。附录全跳。

延伸阅读：ReAct（下期通识 #10，arXiv:2210.03629，ICLR 2023）——CoT 的直系续作：推理步从「想」扩展到「边想边做」（thought-action 交替），Agent 范式的奠基。至此通识线的推理三部曲闭合：CoT（写出思考）→ ReAct（写出行动）→ R1（学会更长思考）。
INSIGHT BY AICoT 的本质不是「教会思考」，是给思维一张纸——显式化的东西才能被检查、被奖励、被接管。

meta/astryx
★ 28,141 · 本周 +13,660（全榜第一）· TypeScript · MIT · Beta
它是干嘛的：Meta 开源的设计系统——在公司内部长了八年、驱动 13,000+ 应用后整体开放：150+ 可访问组件、品牌级主题、CLI 一体，「为人与 agent 共同构建」。
展开详细分析

解决什么问题：AI 生成 UI 的质量上限卡在设计系统——组件库要么 API 封闭、要么与 agent 工具链脱节，人与 AI 各用一套参考。

怎么上手：npm install @astryxdesign/core + theme-neutral + StyleX；npm i -g @astryxdesign/cli 全局装 CLI，「every coding agent knows Astryx」；文档 / Storybook / Sandbox 齐备。

为什么现在火：周增 13,660 全榜第一——「agent-ready 设计系统」把 UI 生成的随机性钉进约束，是设计基建对 agent 时代的第一次整装回应。

与你的方向的连接：设计系统就是 UI 层的本体——schema（组件契约）在上、实例（页面）在下，与 graphify / CLI-Anything 的「把世界翻译成结构」同一思想家族。

Section 04 — 技术方向深度
显式化即接口——从 CoT 到过程监督到可审计 agent
核心判断：「把内部状态显式化」是本周所有关键进展的公共接口——CoT 把思维写成 token（可检查），TOME-Math 把步骤变成监督（可学习），Tool State 把执行变成可回放记录（可审计），Mirendil 把整个实验室变成 agent 可操作的表面（可接管）；而热榜的 goldfish / plannotator 给出对称的一半：显式化让 AI 能干活，验收必须用没有上下文的头脑。显式化程度，正在成为 agent 系统成熟度的真实度量。

① 为什么是现在：R1 证明了规则奖励能激励推理（NO.010），但「奖励什么」悬而未决——奖励最终答案会奖励运气，奖励每个推理步又贵又难标。本周的三篇给出突破路径：TOME-Math 发现教材里现成的「命题-证明依赖链」就是免费的过程标签（38 万条，+16.7pp）；Actor/Judge/Teacher 发现「裁判位」比「演员位」更适合过程监督（72.8→82.9%）；Dense Rewards in GRPO 则泼了冷水——逐步稠密奖励的续采吃掉 91% token，等算力后反输标准 GRPO 14.3 个百分点。结论收敛于：过程监督要的是「对的位置」（裁判位）与「对的粒度」（教材式依赖链），不是「最细的奖励」。

② 大白话 + 类比：把「显式化」想象成把作业从「只写答案」升级成「写全过程」。老师批答案只能判对错（outcome reward），批过程才能看出「哪一步的思路值得表扬」（process supervision）——但逐字逐句批注太贵（Dense Rewards 的 token 账），聪明的做法是让学生写关键步骤（教材的依赖链），老师从「监考员」改当「裁判」（Actor/Judge）。Mirendil 则是这套逻辑的工业级版本：当 agent 的每一步操作（申请算力、跑实验、修 bug）都是显式的、可回放的，整个实验室就变成它的工作台——1 个人 + 99% agent 代码 + $10M 算力的预训练，就是把「显式化」推到组织层面。

③ 原理机制（A→B→C）：A · 显式化创造监督面——CoT 把推理写成 token → 中间步骤进入上下文/日志 → 每一步成为可标注、可奖励、可审计的对象；没有显式化，监督只能落在最终答案上；B · 监督面的正确用法是「裁判位」而非「逐帧打分」——Actor/Judge 证明看完整轨迹的事后归因比事前逐步预测更可靠；TOME-Math 证明「结构化的既有过程」（教材依赖链）比人工造过程标签便宜且有效；Dense Rewards 证明逐 token 打分的成本会吃掉全部收益；C · 显式化扩展到组织层即「可审计的自动研究」——Mirendil 的 Lor 让 agent 自主申请算力、并行拆分子 agent、故障自恢复，每一步留痕；Sage-Taiyi 给闭环装元认知监控（证据/假设/开放问题三本账）；Tool State 把每个计算位点的工具状态成对存档供回放。显式化从「写出来的推理」升级为「可回放的执行」。

④ 代价与证据：显式化有真实代价。Dense Rewards 的 token 账（91%）是显式化过头的直接后果；SO-Arena 的发现是反向警示——能力与可靠性错位（能力第一可靠性第 7），说明「会想」不等于「想得稳」，可靠性需要独立度量与门禁；Robot Memory Clock 揭露时间戳捷径（发呆被记成加班）——显式记录本身可能引入新的捷径学习。正解是 goldfish 原则：执行用有上下文的头脑，验收用没有上下文的头脑；记录要按事件因果组织，不按表面字段（时间/分数）组织。

⑤ 怎么用到你自己的工作流：给任何 agent 流程做「显式化体检」——① 推理是否可见（有 CoT / 计划输出，而不只是最终结果）？② 执行是否可回放（工具调用留痕，能从任意位点恢复重跑——Tool State 的做法）？③ 监督是否站对位置（事后裁判 + 关键步骤抽查，而非逐帧打分）？④ 验收是否换脑（fresh-context 审阅者，如 EGM 的 goldfish / Cloudflare 的 fresh verifier）？四问全过，这个流程就具备了「被自动改进」的资格——这正是 RLVR / harness 循环的准入条件。

⑥ 延伸阅读：TOME-Math（2610.40394）读它的依赖链构造；Actor/Judge/Teacher（2611.17167）读三重身份实验设计；InfraRSI（2611.11558）读锁定不变量防 reward hacking 的具体机制；Mirendil 的预训练博客是「agent 干整个实验室」最详细的工程披露；回看通识线：CoT（显式化思维）→ ReAct（下期，显式化行动）——显式化的粒度一直在扩大，而每扩一步，监督与审计就多一层抓手。
核心判断显式化程度是 agent 系统成熟度的真实度量——监督要站对位置（裁判位），验收要换脑（fresh eyes），记录要按因果组织（不按表面字段）。

今日 4 题：通识 CoT 两题 + 跨期连接两题（NO.010 R1 ↔ CoT；本期热榜 goldfish ↔ 论文裁判位）。干扰项均为常见误解。累计八份未交——今天开始还。

Q1 CoT 提示只在「足够大」的模型上有效（10B 以下反而常为负收益），它的机制解释是什么？提示：01 通识「原理机制」C 步。注意 A 干扰项：问题不在放不放得下示例。

答案：C。论文原话「CoT is an emergent ability of increasing model scale」——10B 以下常为负收益、约 100B 才出现增益。A 错（8 个示例对任何模型都放得下，问题不在上下文长度）；B 是常见误解（CoT 不改参数、不教新技能，只是引导输出格式）；D 无依据——涌现现象在训练数据相同的不同规模间出现，规模才是变量。

Q2 PaLM 540B 仅用 8 个 CoT 示例就在 GSM8K 上超过「微调 + verifier」的 GPT-3，这个对比最想说明什么？提示：01 通识「为什么是分水岭」。注意 C 干扰项：论文强调的是推理步质量而非示例数量。

答案：D。17.9%→56.9%（+39.0）且超过带 verifier 的微调 GPT-3，说明「推理时算力」（多步显式展开）是一条与「训练时算力」并行的能力获取路径。A 过度推广（微调在无数场景仍是必需）；B 错——verifier 无用这个结论论文没有支持，且 verifier 思路正是后来 RLVR 的前身；C 偷换概念——对比的意义在推理步而非示例数。

Q3（跨期连接 · NO.010 R1 ↔ 今日 CoT）从 CoT prompting 到 DeepSeek-R1，「推理」的来源发生了什么本质变化？提示：NO.010 通识「为什么是分水岭」+ 今日「与近期进展的联系」。R1 的纯 RL 恰恰不给人工推理轨迹。

答案：A。CoT 是「写出来」（人类示范格式 + 推理时显式化），R1 是「长出来」（规则奖励驱动 RL，无人工推理轨迹）——监督信号的来源从人类示范换成环境规则，这是 NO.010 深度「奖励来源三部曲」的最后一环。B 与 R1 的核心声明相反（摘要明确「无需人工标注推理轨迹」）；C 忽略了两者的直接血缘（R1 优化目标就是长 CoT）；D 错——R1 产出正是序列推理链，甚至更长。

Q4（跨期连接 · 本期热榜 ↔ 论文）Google EGM 的「goldfish 无上下文审阅」与 Actor/Judge/Teacher 的「裁判位监督」共享什么设计原则？提示：02 热榜 #3 + 03 速递 #5。注意 D 干扰项：两篇结论恰好都指向「少带上下文」的评审者。

答案：B。两篇的公共原则：评审者不能继承执行者的锚定。EGM 的 goldfish 特意不带此前对话（暴露未言明假设）；Actor/Judge 的发现是「演不好但看完整轨迹当 judge 能正确归因」——裁判不需要会演，但必须站在裁判位而非演员位。A 无依据（judge 用的是同量级模型）；C 错——两篇恰好都是让模型做评审；D 与两篇结论相反，多带执行上下文正是「自我锚定」的来源。
