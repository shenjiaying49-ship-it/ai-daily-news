## 站点约定

- 论文 PDF 链接一律指向 arXiv，本仓库**不托管论文 PDF**（`papers/` 仅本地存档，已 gitignore）。
- 不含政策监管 / AI 伦理 / 安全治理 / 公共议程类内容。
- 简报由本地多智能体管线（GLM + WebSearch + arXiv/HF 实抓）生成，经 GitHub Contents API 同步到 main 分支并触发 Pages 构建。
- 排版风格致敬 [linkx-capital/ai-daily-news](https://github.com/linkx-capital/ai-daily-news)。
