## 这是什么

一个**个人 AI 研究学习系统**：每天早上，一组 AI 智能体会自动完成「抓取前沿论文 → 实地核实 → 中文写作 → 渲染网页 → 发布上线」的全流程，产出一份可以直接在浏览器里阅读的日报。它同时是一套**学习系统**——每日通识精读、在线测验、难度自适应、费曼学习法闭环。

设计语言致敬 [linkx-capital/ai-daily-news](https://github.com/linkx-capital/ai-daily-news)（暖纸底 · 紫主色 · 侧边目录 · 自动深色模式）。

## 每天包含什么

每日简报分 7 个板块，按「通识是主线，前沿全量保留」的原则组织：

| 板块 | 内容 | 特点 |
|---|---|---|
| **01 通识精读** | 奠基论文逐日精讲（Transformer → GPT-3 → Chinchilla → …） | 4 周 20 篇顶会经典路线图 + 15 分钟导读路线 |
| **02 GitHub 热榜** | 本周上星最快的 5-8 个项目 | 每项带「▸ 展开详细分析」（基于实抓 README：解决什么/机制/上手/为什么火） |
| **03 前沿论文速递** | 10+ 篇最新论文，按 ★ 难度分组 | 每卡附「INSIGHT BY AI」一行结论 + arXiv/代码链接 |
| **04 技术方向深度** | 一个方向的六段式深析 | 大白话类比 → 原理 → 进展 → 核心判断 |
| **05 初创研报** | 研究驱动的初创/实验室 | tagline + 指标盒 + 要点列表 + 风险（对标 LinkX 研报格式） |
| **06 语料精选** | 用户投放材料的消化结果 | 支持论文 PDF / 文章 |
| **07 每日测验** | 4 道选择题，**页面内直接作答** | 提交即判分；全对升难度（L1 识别 → L5 批判），答错自动降级重讲 |

## 怎么制作的

全流程无人工干预，每天 08:10 由定时任务触发：

```
 定时触发 (每天 08:10)
      │
      ▼
 ┌────────────────────────────────────────────────┐
 │ 1. 采集：并行智能体抓取                          │
 │    · arXiv listing (cs.LG/CL/AI/RO/CV)          │
 │    · Hugging Face daily papers / 热榜交叉验证     │
 │    · GitHub trending + 逐项目实抓 README         │
 │    · 实验室博客 / 初创动态                        │
 ├────────────────────────────────────────────────┤
 │ 2. 核实：逐条验证                               │
 │    · arXiv ID 必须来自实际抓取的 abs 页           │
 │    · ★数 / 增速 / benchmark 数字全部实抓          │
 │    · 不确定的标「真实性待验证」，禁止编造           │
 ├────────────────────────────────────────────────┤
 │ 3. 写作：按内容规范 (SPEC) 生成                  │
 │    · 选稿硬标准：SCI/CCF-A 顶会接收，             │
 │      或「顶尖机构+可复现信号+明确数字」的 preprint  │
 │    · 负面清单零容忍：不含政策/伦理/公共议程         │
 │    · 观点先行，判断句加粗，每条附来源              │
 ├────────────────────────────────────────────────┤
 │ 4. 发布：                                       │
 │    · 渲染自包含单文件 HTML（内联 CSS/JS）          │
 │    · 论文 PDF 本地存档，线上链接直指 arXiv         │
 │    · 经 GitHub Contents API 推送并触发 Pages 构建  │
 └────────────────────────────────────────────────┘
      │
      ▼
 线上更新 https://shenjiaying49-ship-it.github.io/ai-daily-news/
```

**配套的学习闭环**：每日测验得分回填后，次日出题难度自动调整（全对升 L1→L5）；周一自动生成周报并批改费曼作业；通识论文按月度计划（`foundations-reading-plan`）逐日推进。

## 内容质量红线

- 每条新闻 / 论文必须附真实来源链接，抓不到可靠来源就删掉，**禁止编造**
- 论文选稿：SCI 期刊 / CCF-A 同级顶会发表或接收，或有可复现信号的突破性 preprint
- 聚焦技术研究与可落地应用：**不含政策监管、伦理辩论、公共议程类内容**
- 水论文零容忍：无对照实验、纯增量微调、灌水综述一律不收
