Section 03 — 三条趋势判断
T01 · harness 先于权重——改进的「指挥权」上移
NO.007 四篇 RSI 还在改模型本身；NO.008 风向一变：CoEvo-RSI 直接问「当 harness 进化时哪些模型该跟进」，微软 HPO 把 harness 纳入训练闭环（resolve rate 57.8%→64.8%），Epi 把 harness 做成持久化基础设施；同一时间热榜上 ruflo 自称 meta-harness、orca 卖多 agent 编排、K-Dense 拆出 177 个科研技能、Karpathy 观察变成 22 万星 CLAUDE.md。论文与产品在同一时间窗指向同一个层——改进循环的最快路径不在梯度里，在文本级的 harness 变异里。
T02 · 记忆进权重成为赛道共识，但朴素基线反扑
NO.006 的 Latent Compaction 与 Cortex 开了「上下文增益搬进权重」的头；NO.008/009 的 MemT-1.0 与 Deep Fusion Memory 把「记忆即架构」推成集体方向；民间侧 ai-memory（★13.5k）反其道把记忆摊成 git-backed markdown wiki。但 Raw-RAG 在 7 个基准组合中 6 个第一的冷水提醒：复杂 agentic memory 还没过「证据覆盖率」这道朴素关——记忆赛道的下一个分水岭是「找齐证据」，不是「机制精巧」。
T03 · 证据链成为自改进的硬边界——验证机制本身在产品化
从 NO.007 的指标自生成（Terminal-RSI），到 NO.008 的 0/135 审计失败 vs Epi 的可审计纪录，到 NO.009 的 SplatLab（数字绑定留痕 run）与 Cloudflare audit skill（候选交全新 verifier 证伪、覆盖率账本、三态判定）——「验证」正在从论文的附录走向系统的第一等公民：谁把证据链长进 harness，谁的加速才不算生产垃圾。

Section 05 — 技术方向深度（W2 主线合成）
harness 先于权重：有理论、有管线、有生态、有失败样本
核心判断：两周证据合起来看，「先改 harness、模型跟跑」已从单篇论文的观点变成有理论、有工业管线、有产品生态、有失败样本的完整叙事——它的成立条件恰恰是 T03 的证据链：harness 的变异必须被外部验证门约束，否则加速的只是垃圾产量。

理论面（NO.008）：CoEvo-RSI 分层框架——harness 变异（文本级、失败成本≈0）→ 验证筛选 → 好轨迹 SFT 回灌。Qwen3.5-9B 靠「跟跑」在 TraceElephant 超 DeepSeek-V4-Pro +14.16；HPO 做成训练管线 57.8%→64.8%。
成果面：Epi 不刷基准直接刷世界纪录（120 项可查证纪录），证明 harness 层的记忆累积能让改进跨任务复利。
边界面：Into the Unknown 的 0/135——自报产出 ≠ 可审计产出；评估便宜（NO.007 深度三件套）不该滑成造假便宜。
工程面（NO.009）：SplatLab（verified-reproduction 骨干 + 数字绑定留痕 run）与 Cloudflare audit skill（六阶段、fresh verifier 证伪、覆盖率账本）给出同一答案的两份实现——证据链不是约束，是 harness 的承重结构。
消费面：ruflo / orca / t3code / K-Dense 在热榜上的集体出现说明 harness 层产品生态已先行。
与通识线的闭合：InstructGPT（反馈驱动更新）→ ResNet / DPO（增量与闭式）→ harness 分层（NO.009 深度「压缩循环 vs 加速循环」）——两周通识恰好构成这个主线的概念地基。
