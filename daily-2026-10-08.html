Section 01 — 通识精读（今日主线）
FOUNDATIONSLanguage Models are Few-Shot Learners（GPT-3）
Tom Brown et al. · OpenAI · NeurIPS 2020 · arXiv:2005.14165
为什么是分水岭：人类看几个例子就能学新任务，而当时的 NLP 每个任务都要成千上万条微调数据。GPT-3 用 175B 参数（当时非稀疏模型的 10 倍）证明：把模型做大，就能不微调、只靠上下文里的几个例子（few-shot）完成任务，有时追平此前微调过的 SOTA——「in-context learning」从此成为范式，直接铺平了 ChatGPT 的路。

核心思想（讲给 12 岁）：以前的 AI 像一个每换一门考试就要重新补课一个月的学生；GPT-3 像一个读过整个图书馆的学生——考试前不用补课，只要在试卷开头看三道例题，就知道这类题怎么答了。关键：它没有为这次考试改过脑子的任何一根神经（不动权重），全靠「读过太多书」积累的通用能力。

原理机制：自回归语言模型（Transformer 解码器堆叠）→ 300B token 训练 → 推理时把「任务描述 + 几个示例 + 问题」全拼进上下文 → 直接续写答案。Zero-shot（只有指令）/ One-shot / Few-shot 三档，示例越多效果越好，但始终不更新参数。

与近期进展的联系：NO.003 的「Base 模型只差一句开场白」（arXiv:2610.06851）正是这个范式的最新注脚——base 模型的 few-shot 能力一直都在，RL 后训练买到的可能只是一句「开场白」；本期 RSIGym 则把「评估能力」标准化了。

今日怎么读（15 分钟路线）：先看图 1.1-1.3（few-shot 三档示意，全文精华）→ §2.3 数据与训练概览 → 表 3.9（人类评估对比）；§4 各任务细节、§5 检验 contamination 跳过。

延伸阅读：The Illustrated GPT-3 → 明天通识：Chinchilla《Training Compute-Optimal LLMs》（NeurIPS 2022，算力该分给参数还是数据）。
INSIGHT BY AI「不动权重、看几个例子就会」不是魔法，是 scale 的涌现——GPT-3 用 175B 参数把「预训练」和「任务能力」焊在了一起。

★ 97,898 · 本周 +2,607 · TypeScript

▸ 展开详细分析

解决什么问题：「每次开新会话都失忆」——agent 干过的活、做过的决定，换个会话全忘光，要么重新交代一遍，要么把历史全塞上下文烧 token。

NVIDIA/OpenShell
★ 15,357 · 本周 +3,690 · Rust · Apache 2.0
它是干嘛的：自主 Agent 的运行时沙箱——内核级策略执行 + 形式化验证的策略变更，让 agent 能干活但摸不到不该摸的东西。
▸ 展开详细分析

解决什么问题：Agent 要读文件、装包、调 API、用凭证，但不能给它无限权限——企业落地的第一道工程闸门。

核心机制：两条腿——①内核级执行：syscall / 文件 / 网络全插桩，每个连接过策略检查，agent 永远见不到真实凭证（只在请求抵达批准端点时注入）；②形式化验证：策略变更先经验证器检查会新授予哪些风险访问（新主机 + 凭证、新 API 方法），标记后等人审。

怎么上手：curl 一条命令装 CLI + 本地 gateway；支持 Docker/Podman，K8s 用 Helm 部署。

为什么现在火：NVIDIA 出品 + 「多 agent 舰队自治」的运行时缺位被补上；0.1.x 稳定发布节奏。

与你的方向的连接：Agent 大规模自治（ASI 技术面）的前置工程件——没有可控运行时就没有舰队。

INSIGHT BY AI自治的边界由形式化验证划定——「能做什么」白名单化，「想多做」必须过人审。

递归自改进正从单点方法走向可评测、可加速、可架构化的基础设施
1 · 大白话解释：去年讲 RSI 还是「一台会改自己图纸的机床」的思想实验加零星 demo；这周它有了标准考场（RSIGym）、省油变速箱（ThunderSyncRL）和正确装配图（SLA 的状态外置）。就像健身有了统一器械、计时器和训练手册——不同选手的成绩终于可以比了。

2 · 原理机制：RSIGym 把训练 / 推理 / rollout / 评测 / 沙箱服务化，统一 RSI-Index 指标 → 六模型同测分离「模型能力」与「系统能力」；ThunderSyncRL 证明异步梯度与同步训练数学等价（奖励即到即起梯度）；SLA 把研究状态全放 harness、agent 无状态调用，token 省 84%。

3 · 为什么是现在：AIDE²（NO.001）、RSR（NO.003）等实证累积后，领域缺的不是新方法而是「可比性」；benchmark 与基础设施的出现是赛道从研究走向工程的标准信号。

4 · 最新进展：RSIGym（2610.10310，Opus 5 系统 SWE-bench 17.67%→50.33%）· SLA（2610.07625，少 84% token 追平基线）· ThunderSyncRL（2610.05935，1.9× 无损）· ExpDis（2610.10536，探索 / 优化解耦）。

5 · 研究 / 产业影响：RSI-Index 若被广泛采纳，将像 MMLU 之于 LLM 一样重塑资本与研究的注意力分配；对 ASI 时间线的辩论第一次有了可跟踪的量化坐标。

6 · 学习要点：① benchmark 是领域成熟的先导指标；②「状态放哪」（模型内 vs harness）是长程 Agent 的架构级抉择；③ 无损异步 = 免费的 1.9×。
核心判断当一门技术开始建设「考场」而不是只产出「成绩」，它就从论文走向了工程——RSIGym + SLA + ThunderSyncRL 一周内同时落地，是 RSI 赛道基建化的明确信号；下一个值得盯的是 RSI-Index 能否成为行业通用坐标。
