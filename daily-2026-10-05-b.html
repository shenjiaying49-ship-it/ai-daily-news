VIDEO WORLD MODELSCONTROLLABLE GENERATIONStability AI —— 从社区扩散公司转型为「可控视频世界模型」研究公司，两周连出 4Director + SemanTok 两篇可复现工作。

技术路线

三线互咬——一致性蒸馏做快（rCM）、显式几何做可控（mesh + 刚体轨迹替代模糊的图像平面控制）、语义 token 化降成本；基于 Qwen 系底座做工程收敛。

代表工作拆解

4Director 把控制信号从文本 / 轨迹提示升级为显式 4D 场景——物体一次性重建 canonical mesh，逐帧施加刚体变换，相机 / 物体 / 插入物联合编辑；生成的物理一致性来自几何约束而非模型「悟性」。

差异化与同行对比

Sora 类走 latent 端到端（效果好但难精确控制）；Stability 押「显式结构 + 一致性加速」，面向专业制作管线——影视预演、虚拟制片、游戏资产动画、机器人仿真数据合成。

风险：旗舰权重多不开源，社区口碑是护城河也可能是软肋；视频世界模型算力消耗极大，商业化依赖 API；与 Runway / 电影级大厂正面竞争。
核心判断：生成质量的差距在快速收敛，可控性才是视频世界模型的下一个主战场——Stability 用「显式几何」换「导演级控制」，再次证明结构化先验比纯 scaling 更先落地。

SECTION 04 · 技术方向深度分析

ONTOLOGY × AGENTAgent 的显式结构：信念状态、经验树与源学习 本体论-工程

1 · 大白话解释（讲给 12 岁的你）

给 Agent 配一本「工作手册 + 进度条」，而不是让它全靠聊天记录回忆自己干嘛。信念状态 = 进度条（世界现在什么样、还欠哪些活）；经验树 = 错题本（哪些经验可复用）；源模型 = 对某个资料库越混越熟的专属秘书。

2 · 原理机制

PoS：估计世界状态 → 列未完成任务需求 → 监测「持续行动无进展」即报警修正；X-Tree：轨迹按可复用性合并 → 结构化经验喂 RL / 自蒸馏；Source Learning：访问沉淀 → 源能力复用。

3 · 为什么是现在

长程 Agent 的两大故障模式——失忆（上下文滚掉）与空转（原地打转）——在工单、运维、科研助理等真实负载中集中爆发；堆记忆治标不治本。

5 · 研究 / 产业影响

这就是把「本体」做进 Agent 运行时——显式结构即轻量本体，与 ontology-as-kernel / GraphRAG 记忆合流后，将成为长程 Agent 的标配组件。

6 · 学习要点

① 信念状态 ≠ 记忆：前者是对世界与任务的估计，后者只是历史；② 经验结构化的收益来自「可复用性筛选」，不是存得多；③ Mimir 证明结构先验可以做到「允许学习、禁止越界」。

核心判断：Agent 的下一个默认组件不是更大的上下文，而是显式世界结构——谁把本体做进运行时，谁的 Agent 才能长程不崩。

SECTION 06 · 今日费曼时刻

FEYNMAN概念：前向 KL vs 反向 KL

示范解释（讲给 12 岁的你）：拍毕业照。前向 KL 是广角镜头——老师会的每个知识点学生都必须会，代价是每个都不够精（mean-seeking，覆盖所有模式）；反向 KL 是长焦镜头——学生只敢落在老师最可能的少数区域，输出锋利但容易漏解（mode-seeking）。这就是为什么蒸馏研究里，反向 KL 只在「学生自己采数据」时才好用。

自测三问
  1. 为什么反向 KL 蒸馏对 rollout 来自学生还是教师很敏感，前向 KL 却无所谓？（提示：谁的分布在「追」谁）
  2. 用 mode-seeking 一句话解释：反向 KL 蒸馏的模型为何在多样任务上容易漏解？
  3. N-OPSD 为什么选 clipped forward-KL？结合「专家池提供互补覆盖」说说它与覆盖面的关系。
