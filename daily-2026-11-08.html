Section 01 — 通识精读（今日主线）
FOUNDATIONSDeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning
DeepSeek-AI（Guo, Yang 等约 200 人）· 2025-01-22 提交 · v2 2026-01-04 · Nature 645, 633-638（2025）· arXiv:2501.12948 · 通识计划第 8/20 篇
为什么是分水岭：在 R1 之前，「教模型推理」的主流答案是模仿——收集人类思维链做 SFT。R1 给出反例：在完全可验证的任务上（数学/代码），不给任何人工标注的推理轨迹、只用规则奖励跑 RL，推理能力就能被「激励」出来（摘要原词 incentivized）。R1-Zero 从 AIME 2024 的 15.6% 起步，纯 RL 拉到 77.9%（Cons@16 达 86.7%），并涌现自我验证、反思与长思维链；最终版 R1 四阶段管线后 AIME 79.8%、MATH-500 97.3%、Codeforces 百分位 96.3（rating 2029），模型 MIT 协议开源，直接引爆 2025 年初全球开源推理模型潮。它同时回答了昨日通识的悬念：DPO 把 RL 消掉，R1 把 RL 推到极致——当奖励足够客观，RL 不但不脆弱，反而是能力增长的引擎。

核心思想（讲给 12 岁）：教学生做数学题有两种办法：请老师一步步写解题过程让学生背（SFT 模仿），或者只对答案——做对给分、做错不给，让学生自己摸索怎么想（RLVR）。所有人都担心第二种太慢。R1 的发现是：只要题目可以自动判卷（数学/代码天然如此），学生不但能学会，还会自发发明检查、重试、换思路这些从没教过的习惯——就像没人教过你「做完倒回来验算」，但只对答案的考试压力会让你自己长出这个习惯。

原理机制（A→B→C）：A · GRPO：去掉 critic 的策略优化（§2.1 + 附录 A.3）——PPO 需要价值模型当基线，GRPO 同一道题采样一组 rollout，用组内奖励的相对位置当优势：A_i = (r_i − mean)/std，「比同组平均好多少」本身就是基线，critic 整个被省掉；KL 惩罚直接加在损失里；B · R1-Zero：纯 RL 的涌现与缺陷（§2.3）——规则奖励（答案对 + 格式对）下推理能力自发涌现（AIME 15.6%→77.9%），但输出可读性差、中英混杂，且只擅长推理、通用能力弱；C · R1：四阶段工程化（§3）——① 少量冷启动长 CoT 数据 SFT（解决可读性）→ ② 推理 RL（追加语言一致性奖励）→ ③ 拒绝采样 + SFT（804,745 条：约 60 万推理 + 20 万非推理）→ ④ 第二阶段 RL（对齐 helpfulness/harmlessness）。另有蒸馏结论：R1 蒸馏出的小模型全面超过其指令微调基线（§1、附录 F）。

与近期进展的联系：本周速递就是 R1 谱系的扩张现场——TB-MathModel（2611.08237）把「可验证」从数学题推到数学建模科研题（程序不变式 + 624 条 Lean 4 义务双闸门）；A-RSI（2610.38568）解决 RLVR 供给端（程序生成题目 + 训练日志检测过期，11 基准 57.77→61.05）；CoworkOS（2611.03178）把 RSI 自动后训练跑到真实骨干（5 轮 33.19→42.95）；LARC（2610.42149，NeurIPS 2026）把长推理链移植进连续潜空间的图像生成。产业侧：Trajectory 与 Applied Compute（见 05）同周融资，把「规则奖励 + 生产数据」做成企业产品。对照昨日 DPO：DPO 的奖励藏在人类偏好对里（离线、便宜），R1 的奖励来自环境规则（在线、客观）——两条路线在「奖励客观性」光谱的两端，各自成立。

今日怎么读（15 分钟路线）：先读摘要与 Figure 1（R1-Zero 的 AIME 曲线与涌现的 "aha moment" 引文——全文最戏剧性的一页）→ §2.1 GRPO 公式（看懂组内归一化即可）→ §2.3 R1-Zero 结果与局限 → §3 四阶段管线图（Figure 2）→ Table 3 主分数收尾。附录 A 伪代码、B 数据构造按需再查。

延伸阅读：蒸馏细节在附录 F（R1-distill 系列）；下一课预告：通识 #9 Chain-of-Thought Prompting（arXiv:2201.11903，NeurIPS 2022）——回到 2022 年：在 RL 学出长推理链之前，人类先用提示词「骗」出思维链——读完正好看清 R1 把什么从提示词工程变成了训练目标。
INSIGHT BY AI能自动判卷的领域，就不需要老师写示范——R1 的遗产是把「可验证性」变成了训练燃料。

D4Vinci/Scrapling
★ 99,400 · 本周 +8,712（新项目周增第一）· Python
它是干嘛的：把快速 HTTP、隐身浏览器、强解析、并发爬虫装进一个库的全流程抓取框架，页面可直接输出干净 Markdown。
展开详细分析

解决什么问题：现代抓取同时被 JS 渲染、Cloudflare 反爬、网站改版三件事卡住——requests+BS4 和重型 Playwright 各只解决一角。

核心机制：Fetcher 可伪装浏览器 TLS 指纹（impersonate='chrome'）走 HTTP/3；StealthyFetcher 过 Cloudflare Turnstile/Interstitial；解析层支持 CSS/XPath/正则 + Smart Element Tracking——网站改版后用相似度算法重新定位元素；Spider 层带并发、代理轮换、暂停恢复。

怎么上手：pip install scrapling，三行起步：Fetcher.get(url) → page.css('.quote .text::text').getall()；规模化就写 Spider 类，result.items.to_json() 落盘。

为什么现在火：README 首屏即 MCP Server 与 Agent Skill 徽章——agent 可经 MCP 直接用隐身浏览器抓取、截图、复用登录态，内置防 Prompt-Injection 与内容压缩。

与你的方向的连接：对 RSI 系统这是「环境观测」的标准化接口；其「改版后相似度再定位」本质是对环境漂移的自适应修复——思路可迁移到知识图谱 schema 漂移后的实体再对齐。

INSIGHT BY AI抓取库的终局形态是「agent 的感官系统」——MCP 原生 + 反注入，说明它清楚自己的新用户不是人类。

★ 17,203 · 本周 +7,077（近半星七天进的）· TypeScript · Apache-2.0

解决什么问题：README 指出七周内四款封闭 personal-agent 产品密集发布（对标表列 Grok Bot / Meta Muse / OpenAI dots / Manus Cue），「模型、电脑和数据都在厂商一侧」；这是开源版：本地优先、自带 agent。

解决什么问题：AI 生成页面有一堆一眼假的 tells——eyebrow 小字、tracked 大写标签、标题里一个彩色词、满屏空框、末尾必有邮箱订阅。

INSIGHT BY AI传统知识的本体化样本——确定性引擎 + 可溯源断语，这个 repo 的数据治理比多数企业知识图谱还严格。

Section 04 — 技术方向深度
规则奖励的边界扩张——RLVR 从训练技巧到产业基础设施
核心判断：R1 的真正遗产不是「推理模型」，是「可验证奖励」这个接口——本周的三条前沿（科研题基准、任务池自刷新、生产自动后训练）与两家融资初创（Trajectory、Applied Compute）共同表明：规则可验证的边界正在被系统性扩张，而「谁能把领域知识翻译成规则/验证器，谁就掌握了自动改进的钥匙」。

① 为什么是现在：R1（Nature 2025）证明纯规则奖励能激励推理；但 2025 年的共识是它只适用于「有标准答案的封闭题」。本周这个共识被三面突破：TB-MathModel 把数学建模竞赛题（半开放）改造成可验证基准（程序不变式 + Lean 义务双闸门）；A-RSI 让「出题」本身自举（程序生成 + 参考答案独立校验 + 训练日志检测过期）；CoworkOS 把 RSI 自动后训练跑到真实骨干上五轮 +9.76。产业侧同周：Trajectory（$45M）把「专家修正 → RL 奖励」做成平台，Applied Compute（$350M）的 Ari agent 自主跑后训练实验（held-out reward 0.118→0.629，5.3 倍）。论文、开源、融资在同一周指向同一件事，这是范式产业化的典型信号。

② 大白话 + 类比：RLVR 之于 AI 训练，就像「扫码支付」之于交易——它把原本需要人工对账（人类标注/评分）的环节换成了机器可判定的信号。R1 证明了扫码在「数学/代码商店」可行；本周的工作是在给更多商店装扫码枪：科研题商店用「程序检查 + Lean」当扫码枪（TB-MathModel），课程表商店用「训练日志」当扫码枪（A-RSI），生产车间用「专家修正记录」当扫码枪（Trajectory）。扫码枪装到哪，自动结算（自动改进）就通到哪。

③ 原理机制（A→B→C）：A · 验证器即奖励——R1 的奖励 = 答案比对 + 格式检查；TB-MathModel 升级为「6 种可判定不变式的程序检查 + 624 条 Lean 4 形式化义务」——验证器越强，可训任务的开放度越高；B · 供给自举——A-RSI 用固定程序库生成「参考答案可独立校验」的题目（供给不依赖人），再用训练日志的奖励衰减检测任务池过期（课程自适应）——解决「验证器有了，题从哪来」；C · 生产闭环——Trajectory 的 Continual Grading 用 60/375 个任务标注学出元评分器（ranking accuracy 85.7%），再当 RL reward 用（80.0%→84.9%）；Applied Compute 的 Ari 自主策划数据、改代码、启停训练——验证器从「人写的规则」进化到「学出来的评分器 + 自主的实验循环」。

④ 代价与证据：边界仍然真实存在。FrontierPhysics 显示最好配置在真实物理科研上仅约 27% 及格率——瓶颈在「推理严谨性与专家直觉」，恰恰是最难写成规则的部分；IdeaTaste 显示 LLM 的研究品味匹配度仅 18–26%——品味不可验证，偏好优化（DPO 线）因此仍不可替代；ByteDance 的 OPD 研究提醒 RL 学到的能力蒸馏固化时 OOD 会漏 2.45–16.25%——「训完了怎么存」是下一环账单。正反两面合起来：规则奖励扩张的速度，取决于验证器的工程想象力；它的天花板，是人类判断中不可形式化的部分。

⑤ 怎么用到你自己的工作流：把今日通识当作「验证器设计课」——遇到任何想自动改进的流程，先问三个问题：① 结果能不能写成程序判定的断言（答案比对/编译/测试/schema/Lean）？② 题目/任务能不能由程序生成且参考可独立校验（A-RSI 契约）？③ 信号会不会过期、能不能从日志里检测（A-RSI 刷新）？三问都过，就值得搭 RL 循环；任何一问不过，回到 DPO 线（人类偏好）或 harness 线（验证门 + 人工审计）。

⑥ 延伸阅读：TB-MathModel（2611.08237）读它的双闸门设计；A-RSI（2610.38568）读任务刷新的契约；CoworkOS（2611.03178）读自动后训练的迭代曲线；Trajectory 的 Continual Grading 博客是「学出来的评分器」最清晰的工程披露；回看通识线：Chinchilla（算力分配）→ InstructGPT/DPO（人类偏好）→ R1（环境规则）——奖励来源的三部曲恰好是本通识计划的主轴。
核心判断规则可验证的边界在哪，自动改进的边界就在哪——验证器的工程想象力决定扩张速度，人类判断中不可形式化的部分划定天花板。

Section 07 — 每日测验（难度 L2 · 机制理解级）
今日 4 题：通识 DeepSeek-R1 两题 + 跨期连接两题（DPO ↔ R1 奖励来源对照；NO.009 harness 主线 ↔ 本期 Harness-S）。干扰项均为常见误解。累计七份未交——今天开始还。

Q1 R1-Zero 已经用纯 RL 涌现出了推理能力（AIME 15.6%→77.9%），为什么最终版 R1 仍要加入冷启动数据与四阶段管线？提示：01 通识「原理机制」B→C 步。

答案：C。R1-Zero 已证明推理能力可纯 RL 涌现——四阶段管线解决的是它「可读性差、语言混杂、通用能力弱」的工程问题（§3）。A 与论文事实相反（能力稳定存在）；B 错——规则奖励同样适用于代码等任务，且 R1 的通用能力主要靠第三阶段 80 万条拒绝采样 SFT 扩散；D 混淆概念——GRPO 的基线来自组内相对奖励，与 SFT 数据无关。

Q2 GRPO 相对 PPO 为什么可以去掉 critic（价值模型）？提示：01 通识「原理机制」A 步——注意 B 干扰项的陷阱。

答案：A。GRPO 的核心洞察：组内相对奖励（A_i = (r_i − mean)/std）自带基线，「比同组平均好多少」就是优势——critic 的功能被组内统计量替代，不是被删掉不管。B 是常见误解（把「省掉」说成「放弃」）；C 错——R1-Zero 用规则奖励，根本没有奖励模型；D 错——KL 约束的是偏离参考模型的距离，与优势基线是两回事。

Q3（跨期连接）昨日通识 DPO 与今日通识 R1 代表偏好/推理优化的两极，它们对「奖励从哪来」的回答分别是什么？提示：01 通识「与近期进展的联系」最后一句。注意 A 干扰项：R1 的关键恰恰是不给人工标注推理轨迹。

答案：B。DPO 把奖励重参数化进策略（隐式奖励模型，离线学偏好对）；R1 用「答案比对 + 格式检查」的环境规则（在线、无需人类评分）。A 是双重错误——R1 恰恰不给人工标注推理轨迹（这正是它反 SFT 模仿的意义）；C 恰好说反；D 描述的是蒸馏/RLAIF 路线，与 R1 的规则奖励无关。

Q4（跨期连接 · NO.009 harness 主线 ↔ 本期 Harness-S）Harness-S 的「兄弟 harness 池 + 救援重采样」设计，依据的实证发现与带来的训练收益分别是什么？提示：03 速递 #7。注意 A 干扰项：Harness-S 是路由不是投票，且最终蒸馏回单一策略。

答案：C。Harness-S 的贡献是实证刻画了 harness 演化的三个性质（局部性/互补性/非平稳性），并把「兄弟 harness 的成功轨迹」变成 RL 训练资源——最终蒸馏回单一策略、推理时按 Top-k 路由。A 错（路由非投票、非随机）；B 错（最终恰恰收敛回单一策略）；D 抹掉了它的核心发现——「harness 是教材」这一点正是新意。
