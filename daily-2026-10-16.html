Section 01 — 通识精读（今日主线）
FOUNDATIONSDeep Residual Learning for Image Recognition（ResNet）
He, Zhang, Ren, Sun · Microsoft Research · CVPR 2016 · arXiv:1512.03385 · 通识计划第 5/20 篇 · PDF 已入库
为什么是分水岭：ILSVRC 2015 冠军，152 层深度网络 ensemble 把 top-5 错误压到 3.57%（当年人类水平约 5.1%）；关键数据是比 VGG-19 深 8 倍、但计算复杂度反而更低。在此之前「加深网络」是撞墙——20 层以上训练就不收敛或退化。ResNet 第一次把「深」从口号变成可稳定复制的工程事实，此后十年所有主流架构（Transformer 的残差流、各家 CNN backbone）都以它做布线。

核心思想（讲给 12 岁）：每层不必从头学「完整的新特征」，只学「在上一层的输出上，我还差什么」。改稿时只写批注、不重抄全文；接力跑中每一棒只需要在上一棒的位置上继续前进。论文把学习目标从「写完整答案 H(x)」改写为「只写增量 F(x)，答案 = x + F(x)」——如果增量最优是 0，这一层自动退化成直通，什么坏事都不会发生。

原理机制 A→B→C：观察（退化问题）：56 层网络训练误差反而高于 20 层——不是过拟合（训练集上更差恰好相反）、加了 BatchNorm 梯度流也压不住 → 猜想：堆叠的非线性层难以逼近恒等映射（identity），深层优化的目标面太难 → 重写：把层从「学 H(x)」改为「学 F(x)=H(x)−x」，输出 y = x + F(x)；短路连接不引入任何新参数 → 结果：34/50/101/152 层全部成功训练；恒等映射最优时 F→0，网络退回浅层行为——优化路径被大幅缩短，深层第一次变得「好优化」。

与近期进展的联系：残差是贯穿本期所有板块的暗线——昨日通识 LoRA 的 ΔW 是「权重空间的残差」；MaLoW 把流式视频固化进 LoRA 权重（记忆即增量）；MSAR（10-12 速递）证明残差连接本身还有规模化空间（多流注意力残差等算力加速 1.58×）；今日 RSI 四篇的每次自我改进本质上也是一次 ΔW。2016 年的布线思想，成为 2026 年自改进的数学原型。

今日怎么读（15 分钟路线）：§3.1（退化问题的实验证据，两段）→ §3.2（残差公式推导 + 短路连接，全文核心）→ 表 3 / 图 4（34/50/101/152 层对比）；ImageNet 训练细节与附录可跳。

延伸阅读：下期通识预告 InstructGPT（#6，2203.02155）——从「网络怎么布线」到「微调时该听谁的」（RLHF 三阶段的技术面）；可选：GPT-2 的残差流分析、PreNorm vs PostNorm 之争。

Section 04 — 技术方向深度：自改进的样本效率（RSI 周报）【ASI × 本体论】
为什么是现在：本周「递归自改进」四个字同时出现在四篇新实证里——Terminal-RSI（终端闭环重写）、Athanor（自主后训练研究）、AutoSFT（数据研究）、TimeRSI（时序部署自改进）；加上上周的 Harness² 与 Latent Compaction，RSI 从论文名词变成工程节奏——这个密度值得单独深挖一次。

大白话解释：改进模型的传统方式靠人：读失败案例、想假设、写代码、跑实验、写论文，一轮几周。RSI 把「研究员」整个换成 agent：失败 → 归因 → 假设 → 改代码 → 终端 / 沙盒跑验证 → 再来一轮。类比：以前是请外科医生做大手术（几个月一次，一次成败定生死）；现在是每天十次微创——每次只改一小块，失败了便宜，成功了立刻进下一轮。

原理机制 A→B→C（样本效率从哪来）：A. 自动评估信号——终端可执行验证（Terminal-Bench / SWR100）、留出集（Athanor 的 held-out suite）、历史窗口对照（TimeRSI），评估不再需要人；B. 闭环归因与重写——Terminal-RSI 的 RSR 对已验证轨迹自我重写、Athanor 的 agent 自主「读数据-造数据-改算法-调超参」，失败信息直接进下一轮假设；C. 增量落地——每轮改进是一次重写 / 一次数据动作 / 一次策略精炼，不是一次重训练。数字对照：Athanor 把 Qwen3-4B-Base 从 15.9 推到 67.3（≈4.2×，四个 agent × 八卡节点）；Terminal-RSI 过程奖励 0.21→0.37、SWR100 成功率翻倍；AutoSFT 单个分析子代理就贡献 +6.5 IFEval。样本效率 = 评估便宜 + 迭代便宜（增量）+ 失败便宜（沙盒），三者缺一不可。

与近期进展的联系：增量式改进正是今日通识 ResNet 残差思想的参数空间版本——每轮 RSI 的改进就是一次「站在旧权重上的 ΔW」；MaLoW 把记忆固化成 LoRA（记忆即增量）是同一骨架；COUNT 用 host 内存 n-gram 免训练加能力，说明「不训练也能改进」还有第三路线；昨日 Latent Compaction 的压缩即学习则提示自改进的输入（经验表征）本身也在被压缩。

研究 / 产业影响：对 ASI 技术面——瓶颈已不在模型而在循环基础设施：Athanor 展示「改进改进模型本身」的自治形态，L3M 则用「可撤销性」给循环装上审计阀（自改进的第一原则是可回滚）；对你的本体论方向——OntoAct 给出符号层的对应物：把经验抽象成公理再让验证器检查，RSI 的样本压缩在符号层可以做到可证伪。

学习要点：①RSI 的核心不是模型变强而是循环变快；②增量 + 验证 + 沙盒三位一体，缺一个就退回「大模型 + 人肉研究」；③风险侧——Terminal-Bench 各版本分数差异巨大（2.1 的 86.52% vs 3.0 的 16.95%），度量饱和与自生成数据无外部锚的崩塌边界仍未解决。
核心判断RSI 一周四发不是巧合而是节奏——「评估便宜 + 增量落地 + 沙盒失败便宜」三件套把研究循环从月级压到天级；而「增量式改进」正是 ResNet 残差思想的参数空间版——2016 年的布线成为 2026 年自改进的数学原型，本期主线闭环。

1.（通识）论文说更深的 plain 网络「训练误差更高」——这个退化问题不能归因于梯度消失，最有力的依据是？ 提示：01 节③

2.（通识）ResNet 把每层学习目标从 H(x) 改成 x + F(x)。为什么这个「先保底、只学增量」的布线至今仍是规模化架构的通用前提？ 提示：01 节③④

答案：C。残差的核心价值是优化捷径：新层最差也能复制恒等（F→0），于是深层训练不必从零逼近旧功能；这正是 Transformer 残差流的直系来源（D 是误解），与输出大小（A）或正则化（B）无关。

3.（速递 × 深度）Terminal-RSI / Athanor 这类系统为什么能把「研究-实现-评估」循环从月级压缩到几天？ 提示：04 节③

答案：C。样本效率的三件套：评估便宜（终端可执行验证）、迭代便宜（增量落地而非重训练）、失败便宜（沙盒）——循环变快是核心，单步能力（A/B/D 都是误解）不是关键。

4.（跨期连接 NO.006）昨天 Cortex 把「单条上下文增益」蒸馏成低秩 ΔW，今天 MaLoW 把流式视频固化进 LoRA 权重，通识 ResNet 让每层只学 H(x)−x——三者共享的数学直觉是？ 提示：01 节④ + NO.006 深读

答案：A。ResNet 的 F(x)、LoRA 的 ΔW、Cortex 的上下文增益、MaLoW 的记忆固话——同一个骨架：站在已有状态上只学差异，差异空间（残差 / 低秩）低维且好优化。尺寸（B）与延迟（C）是副产品而非动机。
