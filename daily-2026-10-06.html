Section 01 — 通识精读（今日主线）
FOUNDATIONSAttention Is All You Need
Vaswani et al. · Google Brain / Google Research · NeurIPS 2017 · arXiv:1706.03762
为什么是分水岭：抛弃循环与卷积，纯自注意力架构在 WMT14 英德翻译拿下 28.4 BLEU 且训练并行度大增——此后 8 年几乎所有大模型（GPT / LLaMA / Qwen…）都是它的后代。

核心思想（讲给 12 岁）：RNN 像传话游戏，一句话从头传到尾，越传越失真还没法并行；自注意力像把全班拉进一个群，每个人直接 @ 相关的人——任意两个 token 一步直达。Q / K / V 就是「提问 / 索引 / 内容」：我带着提问（Q）去查谁的索引（K）最相关，就把谁的内容（V）拿过来。

原理机制：每个 token 同时发出三份向量——Query（我要找什么）、Key（我是什么标签）、Value（我携带的信息）；注意力分数 = Q·K 相似度 → softmax 归一 → 按权重加权求和所有 V。多头 = 同时用 8 组不同的 Q/K/V 从不同角度看一遍再拼起来；位置编码补上「谁在前谁在后」（注意力本身不看顺序）。

与近期进展的联系：本周前沿 Triadic Linear Attention（arXiv:2609.36529）把它的二维注意力状态升级成三阶张量来扩容量；LOOM 的循环深度也在同一骨架上做加法——分水岭论文的后代仍在快速进化。

今日怎么读（15 分钟路线）：先看图 1（整体架构）与 §3.2.1 Scaled Dot-Product Attention 的公式与图——这两处拿到 70%；再读 §3.1 背景对比；§5 训练细节、§6 BLEU 表、§7 全部跳过。

延伸阅读：The Illustrated Transformer → 明天通识：GPT-3《Language Models are Few-Shot Learners》（NeurIPS 2020）。
INSIGHT BY AI读 Transformer 不是读历史，是读所有现代模型的骨架图纸——「Q 查 K、加权拿 V」这一个动作，撑起了 8 年的模型演进。

Section 02 — GitHub 热榜与开源发布
趋势数据实抓于 github.com/trending（本周榜）；分析基于各项目 README。
DietrichGebert/ponytail
★ 156,283 · 本周 +8,596 · JavaScript
它是干嘛的：一个「prompt 形态的技能」，把一位沉默寡言、只写一行代码的资深工程师的思维装进你的 AI Agent。
▸ 展开详细分析

解决什么问题：AI 写代码的最大毛病是过度工程——你要个日期选择器，它装一个 flatpickr、写 wrapper 组件、加样式表、还要讨论时区。官方对照实测（12 个功能任务、Haiku 4.5、n=4）：代码量 ~54% 更少（最高 94%）、成本 ~20% 更低、速度 ~27% 更快，且 100% 功能等价。

核心机制：它本质上就是一个 SKILL.md 提示词，内置决策阶梯——写代码前先逐级自问：「这需要存在吗？（YAGNI）→ 有没有现成的？→ 一行能解决吗？→…」，在第一级站得住的地方停下来。

怎么上手：Claude Code 两条命令装插件（/plugin marketplace add DietrichGebert/ponytail）；其他 Agent 把 AGENTS.md 复制进项目即可。

为什么现在火：Agent 编码工具爆发后，「如何让 Agent 少写代码」成了新的稀缺能力；仓库自带对照实验数据，可复现。

与你的方向的连接：这是「Insight 先于代码」的极端案例——想清楚了才能写短，与费曼学习法完全同构。

INSIGHT BY AI最好的代码是不用写的那行——54% 的代码量削减来自一个提示词。

paperclipai/paperclip
★ 97,820 · 本周 +6,030 · TypeScript
它是干嘛的：自治 AI 组织管理器——像管一家公司一样管 Agent：定目标、招「员工」（任意 Agent）、批预算、看仪表盘。
▸ 展开详细分析

解决什么问题：同时开 20 个 Claude Code 终端就管不过来；Agent 24/7 自治但无法审计、成本失控、没有组织。

核心机制：四支柱——Agentic Task Manager（任务 / 审批 / 复核门 / 从 diff 与截图验证产出）、Org Chart for Agents（人 + Agent 混合组织架构、权限与边界）、Agent Employee Training（Skill Studio、评测与绩效考核）、Agentic OS（跨运行时、沙箱、SSO、成本控制）。心跳机制：Agent 被任务、跟进消息或定时唤醒，委派沿组织架构上下流动。

怎么上手：「能收到心跳就能被雇」——Claude Code / Codex / Cursor / OpenClaw 等皆可接入，支持手机端管理自治业务。

为什么现在火：多 Agent 并行从演示走向生产，「管理层缺失」是第一个爆掉的痛点。

与你的方向的连接：这是 L3 系统层的「组织本体」——角色、权限、职责的结构化定义，是 Agent 组织化的前置条件。

INSIGHT BY AI多 Agent 时代的第一缺口是「组织架构」，不是模型。

Section 04 — 技术方向深度：在线测试时训练 ASI
Agent 的「边用边学」：从记到学的最后一公里
1 · 大白话解释：以前 AI 出厂后大脑就焊死了，最多翻翻笔记（那是 RAG）。TTT 是让它在干活时真的长出新连接——像考试时允许边考边翻自己的错题本并当场改错；考完新连接可以丢，也可以留着变成永久经验。

2 · 原理机制：ASCENT 三步闭环：Agent 干活 → 冻结的初始副本当「特权教师」对已验证轨迹做事后复盘 → 把复盘蒸馏进持久 LoRA 快权重。RSR 则在训练期先把多 harness 解法自我改写成 11 倍数据再自蒸馏。

3 · 为什么是现在：「信念状态 / 经验树」解决了记的问题，今天 ASCENT / RSR 解决了学的问题——验证信号（任务完成回执）在 agent 环境里天然存在，权重更新的最后一公里被打通。

4 · 最新进展：ASCENT（2610.05303）部署期 LoRA 快权重；RSR（2610.02826）自我改写 5.5 倍数据；VeriHarness（2610.00972）分歧裁决验证闸门；低精度会吃掉 97% 更新（2610.02179）——在线学习的工程暗礁。

5 · 研究 / 产业影响：与显式结构合流即是完整拼图：本体管「记什么」，TTT 管「怎么变成权重」。已部署 Agent 的持续运维成本有望从「周期性重训」降到「在线小步更新」。

6 · 学习要点：① TTT 与 RAG 的分界线是「是否更新参数」；② 特权教师自蒸馏比直接模仿成功轨迹稳（单条轨迹方差大）；③ 在线更新必须配验证门槛，否则错误经验会固化进权重。
核心判断Agent 学习的「最后一公里」已从数据侧打通到权重侧——下一个分水岭是验证信号的工程化：谁能把「这次做得对不对」变成廉价可靠的自动判据，谁就拿到持续学习 Agent 的入场券。

Meta FAIR · 世界动作模型（WAM）线WORLD ACTION MODELS
本周两篇论文 · 核心作者 Amir Bar 等 · 路线源头 V-JEPA 2（arXiv:2506.09985）
tagline：延续「互联网视频预训练 → 机器人行动」路线，本周连发 ProWAM（2610.02508）与 NAVA-WAM（2610.03391）。起源：从「看视频学预测」一路走到「看视频学动作」。

代表成果：ProWAM 联合预测动作与稀疏视觉子目标，LIBERO-Plus 85.8%、RoboTwin 75.7% 新 SOTA，零样本真机 70% vs 基线 55%；NAVA-WAM 直接从无动作标注视频预训练动作先验，绕开表征预训练与 latent action 模型两条弯路。
